# Texto de entrega para a DIO

**Repositório do projeto:** `https://github.com/SEU-USUARIO/linux-iac-usuarios-grupos`

**Descrição:**

Desenvolvi um projeto de Infraestrutura como Código (IaC) utilizando Bash para automatizar a criação de usuários, grupos, diretórios e permissões em uma máquina virtual Linux. O script organiza os usuários em três grupos departamentais, configura diretórios compartilhados com permissões específicas e pode ser executado novamente sem recriar contas existentes. Incluí também um modo de simulação, um script de verificação, testes básicos e documentação dos comandos utilizados. O objetivo é praticar administração Linux, automação, segurança de permissões e versionamento com Git e GitHub.

**Tecnologias:** Linux, Bash, Git, GitHub e GitHub Actions.

Antes da entrega, substitua `SEU-USUARIO` e confirme que executou o projeto em um ambiente de testes e publicou o repositório.
